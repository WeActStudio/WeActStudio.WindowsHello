### WeActStudio Windows Hello 指纹模块 自动驱动安装使用教程

**适配系统**：Windows 10 / Windows 11 **设备特性**：标准 USB Windows Hello 指纹模块，支持系统原生自动安装驱动、即插即用，无需第三方驱动软件

---

## 📌 设备简介

本指纹模块为**Windows Hello 原生兼容生物识别设备**，符合微软标准生物识别协议。电脑插入 USB 后可**系统自动识别、自动匹配、自动安装官方驱动**，无需手动下载、解压、安装驱动程序，开箱即用，支持系统指纹解锁、登录验证。

---

## ✅ 自动驱动安装步骤（全程无需手动装驱动）

### 1. 硬件连接

将指纹模块 USB 接口直接插入电脑 USB-A 接口（建议使用电脑原生后置/前置USB口，避免拓展坞供电不足导致识别失败）。

### 2. 系统自动安装驱动

插入设备后，Windows 系统会自动联网检索、下载、安装**生物识别设备通用驱动**。
桌面右下角会弹出提示：`正在安装设备驱动程序` → `设备已准备就绪，可以使用`。

无任何人工操作，等待 10–300 秒即可完成驱动部署。

### 3. 验证驱动安装成功

右键开始菜单 → **设备管理器** → 展开**生物识别设备**。
列表中正常显示指纹传感器设备，无黄色感叹号、无未知设备，即为驱动安装完成。

### 4. 启用 Windows Hello 指纹登录

设置 → 账户 → 登录选项 → 选择 **指纹识别 (Windows Hello)**，按照系统提示录入指纹，完成后即可使用指纹解锁、登录系统。

## 🔧 异常排查（识别失败/驱动异常）

### 问题1：插入设备无反应、不自动装驱动

- 切换原生 USB 接口，避免集线器、延长线

- 开启 Windows 更新，安装系统可选驱动补丁

- 重启电脑后重新插拔设备

### 问题2：设备管理器带感叹号/驱动异常

- 右键异常设备 → **卸载设备**

- 勾选「删除此设备的驱动程序软件」（如有）

- 重启电脑，系统会**自动重装纯净官方驱动**

- 或者安装本文件下的驱动：MOC-release-signed-4.0.105.5

### 问题3：提示“未找到兼容的 Windows Hello 指纹设备”

- 确认系统已更新至最新版本

- 重启 Windows 生物识别服务：Win+R 输入 `services.msc`，重启 **Windows Biometric Service**

- 删除原有指纹录入信息，重新录入

## 💡 注意事项

- 本模块**仅支持 Windows 原生 Windows Hello**，不支持安卓、Mac、Linux 系统

- 全程无需第三方驱动工具、驱动精灵等软件，避免不兼容导致功能失效

- 初次使用建议联网，保证系统可正常拉取通用生物识别驱动

- 请勿带电插拔频繁，避免 USB 端口瞬时电流损坏模块
